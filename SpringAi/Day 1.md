# What is Information Security?

Information Security (InfoSec) is the practice of protecting information from:

- Unauthorized access
- Disclosure
- Modification
- Destruction
- Disruption

### Goal

Protect the **CIA Triad**

- Confidentiality
- Integrity
- Availability

---

# Why Information Security?

- Protect sensitive business information
- Protect customer data
- Prevent financial loss
- Maintain customer trust
- Ensure business continuity
- Meet legal and compliance requirements

# CIA Triad

Information Security is a balance between:

```text
        Information Security
               / | \
              /  |  \
             /   |   \
Confidentiality Integrity Availability
```

---

# 🔒 Confidentiality

Ensures that information is only accessible to authorized people.

### Goal

Prevent unauthorized access.

### Methods

- Authentication
- Authorization
- Encryption
- Multi-Factor Authentication (MFA)
- Access Control

### Example

Only HR can access employee salary details.

---

# ✅ Integrity

Ensures data remains:

- Accurate
- Complete
- Unchanged

Protects information from unauthorized modification.

### Methods

- Hashing
- Digital Signatures
- Audit Logs
- Version Control

### Example

Bank transaction amount should never be altered.

---

# 🌐 Availability

Ensures systems and data are available whenever needed.

### Goal

Prevent downtime.

### Methods

- Backups
- Disaster Recovery
- Redundant Servers
- High Availability

### Example

Internet banking should be available 24×7.

---

# Information Security = Balance of CIA

```text
Too much confidentiality
        ↓
Hard to access

Too much availability
        ↓
Less secure

Need a balance between all three.
```

# Common Cybersecurity Threats

## 1. Malware

Malicious software designed to damage systems or steal data.

Examples

- Virus
- Worm
- Trojan
- Spyware
- Ransomware

---

## 2. Phishing

Fake emails or websites pretending to be legitimate to steal information.

Example

Fake Microsoft login page.

---

## 3. Spear Phishing

Targeted phishing attack aimed at a specific person or organization.

Unlike normal phishing, it is personalized.

---

## 4. Man-in-the-Middle (MITM)

Attacker secretly intercepts communication between two parties.

Goal

- Steal information
- Modify communication

Example

Using public Wi-Fi without encryption.

---

## 5. DNS Attack

Manipulates DNS records to redirect users to malicious websites.

Example

Typing

```
www.bank.com
```

Redirects to

```
www.fake-bank.com
```

---

## 6. Denial of Service (DoS)

Flooding a server with thousands of requests.

Goal

Prevent legitimate users from accessing the service.

---

## 7. SQL Injection

Injecting malicious SQL queries into an application.

Goal

- Bypass login
- Read database
- Delete data

Example

```
' OR '1'='1
```

---

## 8. Zero-Day Exploit

Attack exploiting a software vulnerability before developers release a patch.

Requires immediate action from security teams.

---

## 9. Insider Threat

Threat caused by employees or contractors.

Can be:

- Intentional
- Accidental

# How to Identify a Phishing Email

## 🚩 Creates Urgency

Examples

- Your account will be suspended.
- Verify immediately.

---

## 🚩 Poor Grammar

Many phishing emails contain:

- Spelling mistakes
- Bad grammar

---

## 🚩 Generic Greeting

Examples

- Dear Customer
- Dear User

Instead of your actual name.

---

## 🚩 Suspicious Email Address

Example

```
support@amaz0n-security.com
```

instead of

```
support@amazon.com
```

---

## 🚩 Suspicious Links

Hover before clicking.

Verify the domain name.

---

## 🚩 Unexpected Attachments

Never open attachments from unknown senders.

---

## 🚩 Requests for Sensitive Information

Legitimate companies never ask for:

- Password
- OTP
- PIN
- MFA Code

through email.

---

# Best Practices

## 🔑 Strong Passwords

- Long passwords
- Mix uppercase and lowercase
- Numbers
- Symbols
- Avoid dictionary words

---

## 🔐 Enable MFA

Provides an extra security layer.

---

## 📧 Beware of Phishing

Always verify sender and links.

---

## 📎 Avoid Unknown Attachments

Download only from trusted sources.

---

## 🔒 Protect Confidential Data

Never share company information without authorization.

---

## 📧 Encrypt Sensitive Emails

Use encryption for confidential information.

---

## 🌐 Use Secure Networks

Avoid public Wi-Fi.

Use VPN if necessary.

---

## 🚨 Report Incidents

If something looks suspicious:

```
Stop
 ↓
Verify
 ↓
Report
```

Report immediately to the Information Security Team.
